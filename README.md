# 하루톨 · Harutol

**하루 한 톨씩 기록을 모으다.**

하루톨은 캘린더를 중심으로 일상의 기록을 모으는 앱·웹 프로젝트입니다. 이 저장소에서는 프로젝트 소개와 개발 과정을 공개합니다. 실제 앱 소스 코드는 비공개 저장소에서 관리합니다.

## 지향하는 경험

- 일기·할 일·업무·공부·메모 등 다양한 기록을 한곳에 모으기
- 부담 없이 기록을 시작하고 습관으로 이어가기
- 휴대폰과 웹에서 기록을 이어 쓰고 다시 찾아보기
- 장기적으로 그룹 일정·기록 공유 지원 검토

위 내용은 제품 방향이며, 구현이 완료된 기능 목록이 아닙니다.

## 현재 진행 상태

기획과 기술 검토 단계입니다. 기존 캘린더 프로젝트를 참고하여 새 프로젝트를 준비하고 있습니다. 아직 Flutter 앱 코드나 배포된 서비스는 없습니다.

- 목표 플랫폼: Android · iOS · Web
- 우선 검토 기술: Flutter / Dart · Firebase
- 장기 목표: Google Play·App Store 출시와 지속 가능한 서비스 운영
