# 2026-11-19 — 기술 검토와 저장소 구성

## 진행한 내용

- 캘린더 기반 개인 기록 앱의 방향을 정리했다.
- Android·iOS·웹을 함께 지원하는 기술 후보를 비교했다.
- Flutter와 Firebase를 우선 후보로 두었다. 최종 채택과 구현은 이후 단계다.
- 실제 코드 보관용 비공개 저장소와 소개·개발 기록용 공개 저장소를 분리했다.

## 기술 검토에서 확인한 과제

- 작성 중 초안과 서버 저장 완료 상태를 구분하기
- 오프라인 재전송과 여러 기기의 수정 충돌 다루기
- 기록 DB와 사진·첨부파일을 각각 백업하기
- 실제 복구 시험과 운영 비용 모니터링 준비하기

## 다음 단계

1. 최소 기록 구조와 데이터 접근 권한 설계
2. 기술 구성 확정과 개발 환경 준비
3. 캘린더·기록 입력을 작은 단위로 구현하고 각 파일의 역할 학습
